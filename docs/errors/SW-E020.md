# SW-E020 project.yaml 的 schema 版本不兼容

> **生成物，请勿手改**：本页由 `scripts/gen-error-docs.ts` 从 `src/app/errors/registry.ts` 生成；修改文案请改注册表后运行 `npm run gen:errors`。CI 的 `npm run lint:errors` 会拦截漂移与手改。

| 项目 | 内容 |
| --- | --- |
| 段位 | SW-E02x 状态 / 版本 |
| 发生了什么 | project.yaml 的 schema 版本不兼容 |
| 原因 | 文件声明的 schema 版本是 {found}，本版本 CLI 支持的是 schema {supported}。 |
| 怎么办 | 若 schema 字段是被误改的，请改回 {supported}；若项目由更新版本的 CLI 创建，请先升级本机 CLI（`npm install -g script-writer@latest`）再重试。 |
| 退出码 | 1（SPEC-03-EXT：运行期错误） |

文案中的 `{key}` 为运行时上下文占位符，输出时由实际值替换。
