# SW-E041 未配置模型凭据，AI 功能未启用

> **生成物，请勿手改**：本页由 `scripts/gen-error-docs.ts` 从 `src/app/errors/registry.ts` 生成；修改文案请改注册表后运行 `npm run gen:errors`。CI 的 `npm run lint:errors` 会拦截漂移与手改。

| 项目 | 内容 |
| --- | --- |
| 段位 | SW-E04x AI 供应商 |
| 发生了什么 | 未配置模型凭据，AI 功能未启用 |
| 原因 | script-writer 的核心工作流（大纲 → 场景 → 导出）不依赖 AI；只有显式调用模型能力时才需要凭据，当前环境变量 SW_LLM_API_KEY 为空。 |
| 怎么办 | 设置环境变量 SW_LLM_API_KEY（另可配 SW_LLM_BASE_URL / SW_LLM_MODEL）后重试；不需要 AI 时可直接使用 `sw draft` 等核心命令。 |
| 退出码 | 1（SPEC-03-EXT：运行期错误） |

文案中的 `{key}` 为运行时上下文占位符，输出时由实际值替换。
