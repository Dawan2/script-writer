# SW-E030 场景 {sceneId} 不存在

> **生成物，请勿手改**：本页由 `scripts/gen-error-docs.ts` 从 `src/app/errors/registry.ts` 生成；修改文案请改注册表后运行 `npm run gen:errors`。CI 的 `npm run lint:errors` 会拦截漂移与手改。

| 项目 | 内容 |
| --- | --- |
| 段位 | SW-E03x 输入校验 |
| 发生了什么 | 场景 {sceneId} 不存在 |
| 原因 | scenes/ 目录中没有编号为 {sceneId} 的场景文件。 |
| 怎么办 | 从现有场景中选择一个编号：{existingIds}；或运行 `sw draft {sceneId} --title "<标题>"` 新建这一场。 |
| 退出码 | 1（SPEC-03-EXT：运行期错误） |

文案中的 `{key}` 为运行时上下文占位符，输出时由实际值替换。

```text
✖ SW-E030 场景 040 不存在
  原因：scenes/ 目录中没有编号为 040 的场景文件。

  详情：https://github.com/Dawan2/script-writer/blob/main/docs/errors/SW-E030.md
```
