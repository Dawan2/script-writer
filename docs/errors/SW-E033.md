# SW-E033 不支持的导出格式：{format}

> **生成物，请勿手改**：本页由 `scripts/gen-error-docs.ts` 从 `src/app/errors/registry.ts` 生成；修改文案请改注册表后运行 `npm run gen:errors`。CI 的 `npm run lint:errors` 会拦截漂移与手改。

| 项目 | 内容 |
| --- | --- |
| 段位 | SW-E03x 输入校验 |
| 发生了什么 | 不支持的导出格式：{format} |
| 原因 | v1 只实现了 markdown 导出（fountain / pdf 属后续波次），收到的是「{format}」。 |
| 怎么办 | 显式运行 `sw export --format markdown`；若是 project.yaml 的 settings.export.default 被改成了不支持的值，请改回 markdown。 |
| 退出码 | 1（SPEC-03-EXT：运行期错误） |

文案中的 `{key}` 为运行时上下文占位符，输出时由实际值替换。
