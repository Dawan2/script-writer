# SW-E010 目标目录非空，初始化已中止

> **生成物，请勿手改**：本页由 `scripts/gen-error-docs.ts` 从 `src/app/errors/registry.ts` 生成；修改文案请改注册表后运行 `npm run gen:errors`。CI 的 `npm run lint:errors` 会拦截漂移与手改。

| 项目 | 内容 |
| --- | --- |
| 段位 | SW-E01x 项目 / 文件系统 |
| 发生了什么 | 目标目录非空，初始化已中止 |
| 原因 | 目录 {dir} 里已有文件；直接初始化可能覆盖你已有的内容。 |
| 怎么办 | 换一个空目录运行 `sw init`；或确认可覆盖后运行 `sw init --force`（同名文件会被项目骨架覆盖，且不可撤销）。 |
| 退出码 | 1（SPEC-03-EXT：运行期错误） |

文案中的 `{key}` 为运行时上下文占位符，输出时由实际值替换。

## 示例输出

```text
✖ SW-E010 目标目录非空，初始化已中止
  原因：目录 ./my-script 里已有文件；直接初始化可能覆盖你已有的内容。
  怎么办：换一个空目录运行 `sw init`；或确认可覆盖后运行 `sw init --force`（同名文件会被项目骨架覆盖，且不可撤销）。
  详情：https://github.com/Dawan2/script-writer/blob/main/docs/errors/SW-E010.md
```
