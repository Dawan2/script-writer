# SW-E013 目标路径已存在且不是目录

> **生成物，请勿手改**：本页由 `scripts/gen-error-docs.ts` 从 `src/app/errors/registry.ts` 生成；修改文案请改注册表后运行 `npm run gen:errors`。CI 的 `npm run lint:errors` 会拦截漂移与手改。

| 项目 | 内容 |
| --- | --- |
| 段位 | SW-E01x 项目 / 文件系统 |
| 发生了什么 | 目标路径已存在且不是目录 |
| 原因 | {target} 是一个文件，无法作为项目目录。 |
| 怎么办 | 换一个目录名，或移走该文件后重试 `sw init <dir>`。 |
| 退出码 | 1（SPEC-03-EXT：运行期错误） |

文案中的 `{key}` 为运行时上下文占位符，输出时由实际值替换。

✖ SW-E013 目标路径已存在且不是目录

  详情：https://github.com/Dawan2/script-writer/blob/main/docs/errors/SW-E013.md
