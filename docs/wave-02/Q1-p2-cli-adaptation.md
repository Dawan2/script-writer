1. **Q1 关闭**。W2 积压清单（`docs/wave-02/implementation-backlog.md` §7 @ `c3c5e8e`）登记的开放问题 Q1（CLI 优先下 P2「服务端脚手架」与客户端-服务端交互面的本波适用性）已由调度器裁定：**T02–T09 不整包丢弃**，服务端/Web 交互面改写为 CLI 等价物，逐项裁定见 §3 对照表。
