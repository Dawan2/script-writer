## 3. 设计裁定

### D1 一张表，一个出口

新增 `apps/web/src/lib/agent-event-copy.ts`，导出唯一入口：

```ts
agentEventCopy(event: AgentEvent): { title: string; tone: "flow" | "result" | "error" } | null
```

放在 `lib/` 而不是组件内部，理由有三：可单测、`07` 可复用取步骤名、组件文件已 1584 行且是四槽争抢的热点文件。`stepTitleFromEvent()` 退化为对该函数的一次调用。

**返回 `null` 只保留一种含义：这条事件不构成用户可见的进展。**当前唯一一类是流式文本增量 `stream_content_block_delta`，而它在 `recentAgentEvents()`（`:47-51`）就已被过滤，因此实际调用中不会出现 `null`。保留这个返回值是给「以后确有该丢的事件」留落点，不是给「识别失败」留后路——识别失败一律走 D3 的回落。

### D2 三层判定，顺序固定

1. **类型登记**：按 `event_type` 查表（§5）。表覆盖后端 43 类 + 前端已识别的其他来源（小说解读 12 类、`worker_activity`、`model_unavailable_retry`、`stdout` / `stderr`、原始流事件）。
2. **文案来源**：每一行声明取哪一种——`后端消息`（后端文案已是用户话术且带动态信息，如集数、审读轮次）、`固定话术`（后端消息含内部信息或不稳定）、`由 raw_json 组装`（只有 `worker_activity`）。
3. **外泄护栏**：任何要展示的文本先过一次检查，命中即改用该行的固定话术。检查项：路径分隔符、`http://` / `https://`、`.mjs` / `.json` / `.md` / `.py` 等文件后缀、连续两个及以上的 ASCII 单词（英文标识与模型名）、`{}` 包裹的参数键名。

护栏是本项的兜底防线：后端将来新增一条带路径的消息时，界面回落到固定话术，而不是把路径推给编剧。F9 的两条现存事件由它兜住。

### D3 未登记类型回落，不丢弃

表里没有的 `event_type` 回落为中性中文话术「正在处理当前阶段」，`tone` 取 `flow`。**不显示英文事件名，也不丢弃**——丢弃会让界面停在上一条话术，用户读到的是一个已经过去的状态。

### D4 关键词判定全部退场

删除 `:326` 的消息关键词正则与 `:552-557` 的 4 处 `message.includes()`。显示与否、显示什么，只由 `event_type` 与 `raw_json` 的结构化字段决定，不再由后端文案的措辞决定。

### D5 删除不可达的活动条目链路

`activityCandidate()`、`activityFromRawEvent()`、`buildActivityItems()`、`makeActivityItem()`、`toolInputSummary()`、`contentText()`、类型 `AgentActivityItem` / `ActivityCandidate` 一并删除（F5）。同时删除同样无调用方的 `eventLines()`。

删除而不是接线的理由：界面形态由 `06`（反馈层）与 `07`（进度模型）定义，本项不擅自新增一个列表区；留着一份「看起来在工作、其实到不了界面」的映射，下一个读代码的人会照它改文案而毫无效果——`C1-W1-17` 删 `top-nav.tsx` 是同一类处置。

**若 `07` 已把这条链路接线或改写**：本项不再删除，改为让它与状态行共用 §5 的同一张表，判据仍是 AT-06。

### D6 `worker_activity` 由结构化字段组装

前端弃用后端拼好的整句，改用 `raw_json` 的 `worker_name` 与消息正文组装成「叙事质量审读：正在核对当前内容。」，去掉「子进程 N」（F8）。`raw_json` 缺字段时回落到固定话术「正在核对当前内容」。**不改后端拼装逻辑**——`agent_runner.py` 归 `42` 与 `37`。

### D7 管理员通道零改动

`admin:jobs` 的 ZDebug 入口（`:1334-1345`）与 `handleOpenDebug()` 不在本项改动范围内。原始事件、原始日志、`raw_json` 全文继续通过 ZDebug 提供给管理员。

### D8 不动的三件事

不改后端一行；不改事件存储与 SSE 载荷；不新增界面形态（列表区、提示条、横幅一概不加）。本项只改「同一块界面上显示哪句话」。
