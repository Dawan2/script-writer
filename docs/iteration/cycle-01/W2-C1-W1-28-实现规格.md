## 3. 三份历史 Agent 文档的失效标注

### 3.1 处置口径

三份文档**原文一字不删**（裁定 5.2 第 4 项、切片 4.5 的禁止项），只在标题下方、原有引言之前插入一个标注块。选「标注不删除」而不是删除，理由是它们记录的是一段真实存在过的代码状态与当时的判断过程，删掉就只剩结论没有来路；但不加标注，文中的改造建议会被后来的槽位当成待办重新立项。

### 3.2 标注块格式（三份统一）

```markdown
> **本文已失效，仅作历史归档，不可作为实现依据。** 标注日期：2026-08-27。
>
> 失效原因：文中描述的 <本文档涉及的已不存在实体，逐个列出> 在当前代码中均不存在。
>
> 当前 Agent 结构以 `Agents/CLAUDE.md` 与 `Agents/.claude/skills/*/SKILL.md` 为准。
```

四个要素缺一不可：**已失效的结论**、**标注日期**、**该文档涉及的不存在实体清单**、**现行出处**。第三项必须逐份写各自命中的实体，不许三份抄同一句——读者要判断的是「我正在看的这一段还算不算数」，一句通用的失效声明回答不了。
