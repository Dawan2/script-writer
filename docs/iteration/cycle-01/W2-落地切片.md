### 1.3 `Agents/.claude` 下的检索命令必须加 `--hidden`

`rg` 默认跳过隐藏目录，而 Agent 的全部 Skill 都在 `Agents/.claude/` 下。不加 `--hidden` 时，检索一个确实存在的字符串也会输出 0 条。本槽第一次扫描 reference 引用关系时就命中了这个假阴性。

**这是一条会让验收失效的规则**：Agent 侧任何以"检索输出 0 条"为判据的验收，命令不含 `--hidden` 即视为无效判定。

### 1.4 无引用方的 reference 实测确认为 2 份

按 Agent 并入文档 3.1 的口径（引用方含 `SKILL.md` 直接引用、reference 之间的引用链、脚本动态注入）逐份核对，无引用方的只有 `full_generate/references/全稿验收规则.md` 与 `full_generate/references/剧本内容与格式规范.md`。可复现命令：

```bash
cd Agents && for f in $(find . -path ./node_modules -prune -o \( -name '*.md' -o -name '*.json5' \) -path '*references*' -print); do b=$(basename "$f"); [ "$(rg -l --hidden -F "$b" . -g '!node_modules' -g "!**/$b" | wc -l)" = 0 ] && echo "$f"; done
```

基线 2 条，`C1-W1-29` 完成后须为 0 条。`C1-W1-34` 的同名检查项按同一命令口径实现，否则会产出 4 条误报而通不过自己的"无误报"验收。
