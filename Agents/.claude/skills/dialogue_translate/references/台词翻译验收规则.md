# 台词翻译验收规则

本文件用于每个翻译单元完成后的复核。

1. 完整：每个台词 ID 恰好出现一次且有目标语台词；不得删除、增加、合并或重排台词。
2. 母稿保护：人物、集数、中文台词和中文剧本的场景、动作不得改动。
3. 语义等效：译文保留原句的对象、事实、否定、条件、信息边界、人物策略、潜台词、关系变化和情绪强度，不新增解释或剧情。
4. 声音一致：用词、句法、礼貌程度、称谓与当前剧情单元的角色阶段一致；不同主要角色不能呈现同一种统一腔调。
5. 本地自然：符合目标 locale 的语法、拼写、口语和文化语境；成语、网文词、梗和脏话按功能与强度等效，不逐字硬译。
6. 可演可读：译文自然、直接、有节奏；过长时按语义拆句，不通过删掉关键信息或堆砌俚语制造“短剧感”。
7. 一致性：人名、称谓、组织、地点和关键概念在全剧保持统一。已有译文只作参考，错误或生硬表达必须修正。
8. 简介：工具指定的首个单元存在 `英文简介` 时，译文必须完整保留故事梗概的主线冲突、关键推进和结局回报；不得改动中文故事梗概，也不得写成创作说明。
9. 剧集名称：存在中文剧集名称时，必须填写简洁的目标语剧集名称，保留本集的核心冲突、对象或钩子；中文名称不得改动，目标语名称不写括号。

工具检查负责第 1、2、8、9 项和文件一致性；第 3 至 7 项必须在单元翻译时由模型复核，并在最后的海外审稿中再次取证检查。
