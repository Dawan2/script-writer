# 台词本土化原则

本文件只用于把已经定稿的中文台词转成项目指定 locale 的可演台词。

## 等效目标

- 先判断说话者在这一句中要争取、拒绝、试探、遮掩、施压、交换、安抚还是切断关系，再用目标语实现同一行动。不得只替换字面，也不得借翻译补充解释、承诺、羞辱或剧情事实。
- 保持中文台词的已知信息、对象、权力位置、潜台词、情绪强度和回应关系。中文含糊处保持同等含糊；中文没有揭示的身份、秘密或关系不能提前说破。
- 译文要能被演员自然说出。优先使用目标市场日常口语、主动表达和清楚节奏；不用教科书句式、机械俚语、统一狠话或所有角色共用的网络腔。

## 人物声音

- 依据当前单元的角色口吻与阶段变化区分词汇、句长、礼貌程度、称谓、回避方式和压力下的失控方式。不能把后期成熟口吻提前给前期角色。
- 同一句意图在不同年龄、职业、关系距离和权力位置下应有不同说法。主要角色遮去名字后，仍应能从节奏和策略辨认。
- 人名、组织、地点、称谓和关键概念按项目既有映射保持统一。没有可靠映射时保留原名或采用通行转写，不临时创造多个版本。

## 文化表达

- 成语、网文词和网络梗按场景功能寻找目标语等效表达：它在此处是在羞辱、立誓、反击、示弱还是制造亲密。无法保留双关时，优先保留剧情作用和人物关系，再保留字面意象。
- 不把目标地区当作单一俚语库。没有证据时使用自然、清晰的通用表达；不要伪造地域口音、法律术语、宗教说法或流行梗。
- 脏话、侮辱和敏感称谓保持相同意图与大致强度，避免直译后无意升级或软化。平台或地区规则只约束表达方式，不得静默删除剧情信息。

## 英语短剧提示

- 英语台词优先短句和强动词；一句约 10 个词以内通常更利于快节奏表演，但这不是硬性数字。若压缩会丢失条件、否定、关系或策略，应保留必要长度并自然拆句。
- 使用项目指定的英语变体，不混用美式、英式或其他地区拼写和习惯。

# 字幕可读性与断句

在进行台词翻译时，需要注意字幕的可读性：

- 优先保留一轮交锋中的行动与回应，用简洁句法删去目标语中不必要的重复主语、解释和填充词；不得删去否定、条件、对象、证据和关系称谓。
- 需要拆句时，在标点后、连词或介词前寻找自然边界；不要拆开冠词与名词、形容词与名词、主语代词与动词、助动词与主动词、姓名内部。
- 打断由他人或动作造成时使用目标语言自然的中断形式；同一人物犹豫或话尾消失时使用停顿形式。不要给每句机械添加破折号、省略号或感叹号。
- 目标语若需要两行展示，断行要保持语义组块完整。台词译稿仍保留一条台词对应一个台词 ID；不得为了排版拆散台词 ID 或复制中文母稿。
