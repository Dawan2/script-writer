# 分析报告与审批模板

本文件只用于形成管理员可审阅的分析报告。

```markdown
# Agent 进化分析报告

## 分析范围

## 证据概览

## 优化建议

### 优化项标题
- 现象：
- 证据：[event:1]
- 根因假设：
- 调整对象：`Agents/.claude/skills/<skill>/...`
- 具体方案：
- 预期收益：
- 副作用：
- 验收指标：
- 回滚点：

## 执行优先级

## 验证与回滚
```

证据不足时，`## 优化建议` 只保留：

```markdown
### 不建议本次修改
- 判断：
- 证据缺口：
- 后续采集：
```

报告通过校验后仍须由管理员在后台审阅，未审阅不得进入执行。
