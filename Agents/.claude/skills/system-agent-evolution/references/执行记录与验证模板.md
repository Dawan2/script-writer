# 执行记录与验证模板

本文件只用于获批执行后的记录；系统验证结果由后端写入。

```markdown
# 执行记录

## 执行范围

## 实际变更

## 未执行项及原因

## 指标对照

## 回滚方法

## 系统验证结果
```

后端计算实际变更并写入 `verification.json`：

```json5
{
  "schema_version": "1.0.0",
  "status": "passed", // pending、passed 或 failed
  "changed_files": ["Agents/.claude/skills/example/SKILL.md"],
  "commands": [
    { "command": "npm run check", "status": "passed" }
  ]
}
```

执行记录必须列出实际改动文件；无生产改动时写“未修改生产 Skill”及原因。不能把计划中的文件、未通过的命令或未获批项写成已完成，也不要手写系统验证结果。
