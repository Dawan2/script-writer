# 提案与人工评审模板

本文件只用于写项目复盘提案。

```markdown
# Skill 改进提案

## 分析范围

## 证据摘要

## 候选改动

### 改动标题
- 证据：[E-001]
- 调整对象：`Agents_new/.claude/skills/<skill>/...`
- 具体改动：
- 质量验收：
- 效率验收：
- 回滚方式：

## 不建议改动的事项

## 人工评审
- 评审状态：待人工评审
```

证据不足时，`## 候选改动` 只保留以下内容：

```markdown
### 不建议本次修改
- 判断：
- 证据缺口：
- 后续采集：
```

提案不等于批准。检查通过后只生成待评审元数据，生产 Skill 的改动必须在独立、明确批准的工作中进行。
