# 角色小传编写原则

本文件只用于基于剧本大纲，编写可用于人物资产生成的角色资料、关系弧光和阶段变化。

## 名称一致性

- `人物名称` 使用剧本大纲关键角色名称映射中的中文名称；
- 英文名称以大纲映射为准；目标发行地区为国内时，角色小传标题不显示英文名称；
- 其他地区的角色小传标题使用“中文名称（英文名称）”；
- 其他角色的名称，也使用同样的原则进行生成；

## 事实与范围

- `3.1-outline.json` 是角色范围、剧情行动和阶段顺序的唯一事实来源。只为其中的关键角色建档，不补造人物、经历、关系或结局。
- 角色设定可以将大纲中的身份、处境和行动具象为稳定表达，但不能添加会改变剧情因果的能力、秘密、事件或关系。
- 后期获得的身份、资源、认知、关系和口吻不能提前写入前期阶段。

## 人物形象

- `性别`、`国籍`、`年龄`、`身份`、`外貌`、`穿着`、`性格`共同构成人物资产生成的稳定参考。年龄取主线中出现的主要年龄，写为明确年龄；外貌和穿着写可被镜头识别的特征，性格写可转化为行动和反应的稳定倾向。
- `核心诉求` 写角色想得到、守住或证明什么；`人物难题` 写其为此遇到的阻碍、局限或两难。二者都必须能从角色在大纲中的行动得到解释。

## 关系与弧光

- 用事件路径说明变化：角色的选择 -> 他人的判断或回应 -> 局面代价 -> 关系位置的改变。
- 每个关键角色都要有自己的目标、恐惧、利益或误解，不能把其他角色写成只为烘托主角而行动。
- 弧光不是性格标签的正反转换，而是角色在压力下改变策略、关系、认知或承担代价的过程。

## 人物关系图谱

- `是否主角` 全部角色中只能有一位为 `true`；这位角色作为图谱中心，不能按戏份猜测或设置多位中心。
- `身份` 说明该角色在故事中的稳定位置，展示在关系图谱卡片下方；主角在界面中固定标为“主角”。`所属阵营` 使用可归类的利益立场、家族或组织名称；同一阵营必须使用同一个名称。
- `人物关系` 只记录大纲中已经成立的稳定关系，使用双方均可理解的不超过 12 个字符的短标签，例如“商业对手”“母子”“秘密同盟”。不得关联自身，不得重复关联同一角色。
- 每位关键角色都至少关联一位其他关键角色；所有关键角色经关系链可连接到主角，避免把独立人物或纯功能角色放入图谱。
- 图谱字段只供关系图谱使用，不写入 `output/角色小传.md`，也不由后续剧本写作工具返回。

## 阶段变化

每条阶段变化对应“开篇”或一个与该角色相关的剧情单元，在该表格中，记录了伴随故事情节发展下，该角色不同阶段的信息。
只要在该阶段中，角色在任意一列中的信息发生变化，就需要为该阶段添加一行记录。

- `故事阶段` 使用大纲中的“开篇”或单元名称并保持时间顺序。
- `身份与处境` 写当下的目标、风险、资源和关系位置；不能只写相对上一阶段的变化。
- `人物形象` 结合当前阶段的变化，依据人物形象中的年龄、身份、外貌、穿着和性格，组成该阶段完整的当前形象，不能只写相对上一阶段的变化。
- `口吻` 完整写该阶段如何组织语言、保留信息、试探、施压、回避或求助，以及压力下的说话方式；不只写“更直接”“不再克制”等变化标签。
