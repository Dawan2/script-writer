# 剧本去AI味原则

## 修订目标

让剧本读起来像具体人物在具体处境里争取、回避、试探或反击，而不是编剧替人物概括剧情、主题和心理。去AI味不是把所有台词改得口语化，也不是把剧本写得更短；它要保住信息、因果和角色差异，让信息由可拍的行动、关系和潜台词承担。

`output/原始剧本.md` 是故事事实基线，`output/去AI味剧本.md` 是唯一可写交付。已有去AI味剧本时，优先保留其中用户已确认或已手动调整的内容；只修改本次实际命中的问题。

## 逐场工作法

### 1. 先划定不可改变的内容

每场开始前，先能回答以下问题：

1. 谁想得到什么，谁在阻止他。
2. 人物用什么策略推进、隐藏、试探或反击。
3. 这一场开始前谁知道什么，结束后局面具体改变了什么。
4. 哪些动作、物件、台词和集尾问题必须保留，才能让下一场或下一集成立。

答案来自原剧事实和已写正文，不从“更有意思”的愿望中补造。无法确认时，保留原句的事实信息，只压缩无效修辞。

### 2. 诊断，而不是全文套替换

阅读[剧本去AI味模式库](剧本去AI味模式库.md)，只标记确实造成以下问题的片段：

- 说了人物、观众或镜头已经能看出的结论；
- 用宏大意义、万能评价或模板化转折代替具体戏；
- 所有人说同一种完整、均匀、无策略的句子；
- 为了“高级”堆砌同义词、三段式、破折号或金句；
- 把聊天回复、创作说明、知识免责声明混进剧本正文。

不能按词表扫雷。一个人物在施压时可以连用三句短语，喜剧人物可以故意重复，悬疑场可以用停顿、破折号和省略号；它们有明确的角色、冲突或节奏功能时，都是有效戏，不应被清除。

### 3. 以戏替代解释

按问题的最小范围改写，优先使用下列办法：

| 原有问题 | 优先改法 |
| --- | --- |
| 空泛地说“关系紧张、局面危急、人物成长” | 写出回避的眼神、被收走的物件、未接的电话、改变的站位或迫使对方选择的台词。 |
| 台词把心思说尽 | 保留人物想达成的目的，让其通过试探、答非所问、打断、转移、反问或条件交换表达。 |
| 反复解释同一信息 | 留下最有行动力的一次，其他句子改为反应、后果或删去。 |
| 每个角色口吻相同 | 从身份、关系、当下压力和策略出发调整用词、句长、回避方式和攻击方式，不凭空添加地域口音。 |
| 句子工整得像摘要 | 让节奏跟着场面走：紧张处可短促、试探处可留白、情绪转折处可出现不完整句，但不能丢失关键事实。 |

改写后仍须能由演员表演、由镜头拍摄。动作写可见、可听见、可执行的内容，不写“她很崩溃”“气氛变得复杂”这类内心判断；若原句承载了必要信息，要把信息转移到台词、动作或可见反应中，不得直接删空。

### 4. 保留“人味”的正确来源

原始 Humanizer-zh 强调个性、节奏、复杂感受和具体细节。在剧本中，它们的来源只能是人物和场景：

- **个性**来自角色声线、价值取向、口头习惯和当下策略，不来自编剧插入第一人称观点。
- **节奏**来自冲突强度、停顿、打断、动作承接和信息揭露，不来自随意把句子拆碎。
- **复杂感受**通过矛盾行为、没说出口的选择和关系反应表现，不写成心理分析。
- **具体细节**只能取自原剧、已给定世界观或当前场景；不补造品牌、制度、地方习俗或现实经历。
- **幽默、锋芒和强记忆点**可以保留。只有当“金句”脱离人物、行动和后果，只剩主题口号时才改写。

原剧已有旁白、内心独白、方言、外语台词或非标准标点时，先判断它是否承担人物信息、世界观或节奏功能。它有功能就保留；本 Skill 不负责翻译、统一术语或重设语言风格。

### 5. 朗读与连续性复核

逐集朗读动作和台词，像演员排练一样检查：

1. 说话的人是否在做一件事，而不是替观众总结。
2. 对手是否有可回应、可误解、可抵抗的空间。
3. 相邻台词是否有推进、反转、代价或新的问题，而非同义重复。
4. 场景收束后，人物关系、已知信息和集尾承接是否仍与原剧一致。

只在发现具体问题时返修，不为追求“变化”而改动已经有效的场景。

## 不可突破的边界

- 不改变人物目标、关系、身份、已知信息、事件因果、时空、场景动作、分集标题、顺序和集尾承接。
- 不新增剧情、人物设定、作者观点、创作说明、地方口音、俚语、文化标签或现实制度细节。
- 不删除已有专名、外语台词和语言设定；台词翻译由独立翻译阶段处理。
- 不在正文中加入“以下是”“修改说明”“已优化”等交付元话语，也不附带改写总结。
