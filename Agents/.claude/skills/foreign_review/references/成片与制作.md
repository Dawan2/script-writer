# 成片与制作

只用于完成“成片与制作”评分，面向 AI 生成成片而非传统拍摄预算。

1. `内容量承载`：先读取总集数、场次、台词量、动作量和单集极值。30 集及以上可按完整全稿评估；10 至 29 集需说明部分交付的判断边界。用户目标集数用于交付规划，不以其差异直接下调。每集需有足以支撑 90 秒的可视内容；最终以目标语样读计时判断，不能只凭中文字数断言超时。
2. `旁白、对白与画面分工`：抽象情绪、心理判断和文学修辞必须能改写成可见动作、表情、道具、声音或镜头关系。
3. `画面可表达性与目标语台词`：检查关键戏是否可视化，目标语台词是否能自然、短促地承载与中文母稿相同的情绪与行动，而非长段解释；存在中目标语并列的剧集标题时，抽查目标语名称是否保留中文标题承诺的核心冲突、对象或钩子。
4. `人物与资产一致性、镜头与场景连续性`：检查角色、服装、伤势、时间、道具和位置连续性，并识别可复用与高复杂资产。

- 医疗、多人动作、车辆、枪械、血迹、复杂特效和大规模人群须纳入制作风险或试做计划；具体修改动作只放到 P0/P1。
- 评分卡四项依次使用：`内容量承载`、`旁白、对白与画面分工`、`画面可表达性与目标语台词`、`人物与资产一致性、镜头与场景连续性`。
