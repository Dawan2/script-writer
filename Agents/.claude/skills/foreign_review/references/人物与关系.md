# 人物与关系

只用于完成“人物与关系”评分，沿着人物推动剧情、关系施压、对手反制、人物变化的顺序判断。

1. `主角是否有主动目标`：找出目标、资源、主动选择和后果；只受害、被救或被告知不等于能动性。
2. `核心关系是否持续变化`：每次推进都要有新的行动、边界、利益冲突或互相理解。爱情线还要检查权力差、责任承担和最终选择。
3. `对手是否形成有效反制`：对手应有自己的目标、策略和反制能力，不能每次都被主角资源瞬间压平。
4. `人物弧光与配角作用`：人物变化要由不同选择构成；配角至少在一次关键节点做出不完全服从主角的选择，而非只提供信息或障碍。

- 评分卡四项依次使用：`主角是否有主动目标`、`核心关系是否持续变化`、`对手是否形成有效反制`、`人物弧光与配角作用`。
- 改写项目可用 `4.1-character.json` 的主角、身份、所属阵营和人物关系图谱核对人物设定是否与正文矛盾。图谱必须有唯一主角、全部角色可经关系链连接到主角；关系标签应简短、准确，不得将正文之外的信息写入卡片。发现身份、阵营或关系与正文不一致时，归入“人物与关系”返修。评分和报告仍只引用正文证据。
- 改写项目另核对 `3.1-outline.json` 的关键角色名称映射：需要翻译时，中文正文使用中文名称，目标语提及角色时使用英文名称；不需要翻译时，正文始终保留原著中文名。出现同一角色多次改名或名称错配时归入“人物与关系”返修。
