# 市场与选题

只用于完成“市场与选题”评分，按观众从点开到继续追看的顺序判断。

1. 先判断“核心卖点是否成立”：正文是否已经建立可复述、可感知的观看承诺。
2. 再判断“标题与类型承诺是否一致”：标题、首集和核心关系是否在卖同一种产品。
3. 再判断“受众与市场是否匹配”：目标受众、情绪回报和地区资料是否指向同一观看需求；资料不足只写判断边界。
4. 最后判断“卖点是否持续兑现”：前段建立的承诺是否在中后段持续升级，而非只出现在标题或首集。

- 标题、人物标签和宣传语不是卖点证据。区分“能让人点开”的极端事件与“能让人追完”的关系或爽感承诺。
- 识别受众分裂和类型漂移，输出保留什么、停止押注什么、为什么；不编造竞品、平台数据或当地用户偏好。
- 评分卡四项依次使用：`核心卖点是否成立`、`标题与类型承诺是否一致`、`受众与市场是否匹配`、`卖点是否持续兑现`。
