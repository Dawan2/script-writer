# 发行与风险

只用于完成“发行与风险”评分和风险复核，按观众会不会持续追看、内容有没有扩散点、呈现是否越界、价值后果是否成立的顺序判断。

1. `用户粘性`：判断目标观众是否能持续获得欲望投射、情绪回报、新鲜感或关系附加价值；再核对中后段是否有主线松动、爽点断档或关系线脱离主线而造成流失。它评估的是全剧追看的理由，不重复评分单集钩子和集尾卡点。
2. `传播潜力`：判断是否有脱离上下文也能看懂的名场面、视觉或情绪冲击、角色记忆点、金句和可二创素材，并核对题材是否有可讨论的差异化切口。只能依据正文识别传播素材，不得虚构竞品数据、播放数据或平台传播结果。
3. `内容合规性`：检查暴力血腥、性与低俗、未成年人、犯罪、赌博、毒品、自伤、迷信、宗教、政治和歧视等内容的呈现尺度、语境与累积效应。重点不是题材中是否出现相关元素，而是是否渲染、刺激、引导模仿或超出审稿信息中的“内容分级”。
4. `价值观导向`：检查全剧的善恶因果和行为后果，尤其是违法获利、私刑复仇、以暴制暴、赌博、控制关系及性别或群体刻板印象，是否被无成本地美化。基于剧情的价值后果判断，不写泛泛的“正能量”结论。

- 高风险内容、需要平台或人工复核的事项，归并到 P0/P1 与“风险与复核”。改编权、素材权利和法律意见不作为本维度检查项；材料缺失时写入判断边界或风险复核，不凭剧本文本推断权利状态。
- 评分卡四项依次使用：`用户粘性`、`传播潜力`、`内容合规性`、`价值观导向`。
