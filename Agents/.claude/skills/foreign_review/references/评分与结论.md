# 评级与结论

仅在准入标准为“通过”或“部分通过”后，用于评分工具完成归并后的综合判定、六维结论和总体结论。

- 每个检查项先在 `runtime/review-scoring.json` 填写 0-100 分；维度分和总分由“计算审稿评分”按[评分表](评分表.json5)加权计算。不得用字母评级平均替代计算，也不得手改评分卡中的评级。
- 检查项和维度评级按分数换算：`98-100` 为 `SS`，`90-<98` 为 `S`，`80-<85` 为 `A`，`85-<90` 为 `A+`，`70-<75` 为 `B`，`75-<80` 为 `B+`，`60-<70` 为 `C`，`<60` 为 `D`。总体分数位于所属区间上三分之一时加 `+`，其余使用基础评级；不使用负号，`SS` 不加符号。
- 维度结论：`A/S/SS` 为“通过”，`B/C` 为“可改进”，`D` 为“不通过”。
- 分数、权重和 `runtime/review-scoring.json` 仅为内部计算状态。评分卡、Markdown 报告、网页、Word 和 PDF 只能呈现字母评级，不呈现百分制、总分或权重。
- 综合判定直接写在“评级概述”标题下，不另设小标题；随后依次展示审读范围、审稿方法和维度结论。
- 综合判定从正文提炼本稿最主要的成立点、主要损耗发生在哪一段、这些问题如何影响最终情绪回报，以及应保留和重写什么。不得把六维评级换成一段文字重复一遍，也不得连续罗列字母等级。
- 总体结论仅可为通过、返修、淘汰/重选或补材料。“通过”至少需要总体基础评级为 `A`、六维没有 `D`、没有 P0、没有未关闭的高风险人工复核项。
- 缺少会影响判断的市场、平台、时长或权利资料时，说明边界；只有该缺失阻止用户所要求的结论时才使用“补材料”。
