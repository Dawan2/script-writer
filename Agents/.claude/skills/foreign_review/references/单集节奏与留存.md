# 单集节奏与留存

只用于完成“单集节奏与留存”评分，只回答观众在每一集会不会继续看，不重复判断主线和终局是否成立。

1. `开场钩子与首次情绪释放`：检查前 3 秒危机、反常或冲突，以及前 15 秒是否有首次情绪回报。
2. `单集目标与结果反转`：每集应有明确任务、阻力和改变局面的结果，不能只交换信息或重复情绪。
3. `卡点与集尾悬念`：卡点必须改变下一集的目标、风险或关系，单纯威胁、表情或未兑现句子不算有效卡点。
4. `重复控制与长线追看`：按故事单元识别重复的冲突模型、连续说明、没有新选择的温情段和反派收束后的拖沓；判断主悬念是否持续提供追看理由。

- 内容量承载归“成片与制作”，本维不以台词多来代替节奏快。
- 评分卡四项依次使用：`开场钩子与首次情绪释放`、`单集目标与结果反转`、`卡点与集尾悬念`、`重复控制与长线追看`。
