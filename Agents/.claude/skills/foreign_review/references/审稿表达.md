# 审稿表达

只用于把已经核验的剧本事实写成评分卡和用户报告中的结论、问题说明与修改建议；不改变评分、评级、原稿证据或审稿范围。

## 写法

1. 每个判断先说清对象，再说明发生了什么，最后落到它对观众、人物、故事或制作的影响。对象可以是具体人物、某条剧情线、某个阶段或全剧，不能只堆叠抽象名词。
2. 用人物的选择和剧情事件承载判断。不要只写“关系成立”“卖点有基础”“资源便利”“情绪不足”；要说明谁做了什么、哪个转折缺了什么、因此削弱了什么。
3. 面向读者把因果说完整。类似“A 和 B 能支撑追看”的压缩表达，应改为“全剧中，A 带来的悬念与 B 的持续变化，能够推动观众继续观看”。
4. 结论可以专业，但术语必须落回具体内容。“卡点”“人物弧光”“主线”“规则”“情绪回报”等词后，要紧接其对应的剧情事实或观看结果。
5. 信息缺失时，直接写明缺少什么材料，以及这会限制哪项判断；不要写“无法可靠确认”“经核对”“工具识别”等过程话语。

## 分段要求

- **一句话评估、维度判断、维度结论：** 用完整句说明主要成立点和主要问题，避免把多个名词并列后接“成立、可保留、能支撑、需补强”。
- **综合判定：** 按“剧本最有力的行动或关系线 → 问题出现在哪一段 → 为什么会影响情绪回报或投产 → 返修优先顺序”组织，不复述评级。
- **检查项问题说明：** 先概括该项在剧中如何运作，再指出具体缺口和后果；不要把证据清单改写成一句流水账。
- **核心卖点：** 写清观众会先看到什么、为什么愿意继续看，以及这条承诺如何贯穿前中后段。
- **P0/P1：** 标题说清核心问题；正文写出已发生的剧情、实际影响和可执行的改法，不用工程化标签替代判断。

## 禁止项与复核

- 不写口号、反问、自问自答、对仗式空话、模型或工具过程、创作说明。
- 不用“正文出现/显示”“证据见正文”“本次审读/核对”“模型分析”等话语替代判断。
- 不为显得口语化而加入闲聊、夸张修辞或无证据的情绪判断。
- 生成报告前逐句默读：读者能否一遍听懂“谁、发生了什么、为什么重要”。不能时重写，不新增或删改剧本事实。
