# 正文审读与取证

只用于建立审读范围、全文取证和填写审读台账。

- 以 `runtime/review-source-index.json` 的结构状态决定称呼。连续“场<集号>-<场号>”与“第 X 集”都可归并为“规范分集”；只有“规范分集”可写第 X 集，其余使用场次、候选单元或正文行号。
- 全剧判断必须覆盖全部正文行。先记录集数、场次、台词量和文本量，再单独审读第一集、前三集、一卡、每个故事单元、中后段、结局和索引异常区间。
- 所有内容结论引用当前剧本文本的真实行号。任务书、梗概、人物小传和外部意见不能替代正文证据。
- 每个审读单元记录剧情功能、冲突、选择、结果、卡点、动机、规则变化、矛盾点和证据。无法判断时写“正文未交代”，不要补全作者意图。
- 写入审读台账的记录必须与索引单元一一对应，并包含 `id`、剧情功能、冲突、选择、结果、卡点和证据；人物动机、规则变化、矛盾点可为空数组。
- 每条证据使用 `起始行`、`结束行`、`说明`，且必须位于该审读单元内。先写记录，再调用“写入审读台账”工具。
- 外部意见先核验事实；未证实意见不得进入正式报告。
