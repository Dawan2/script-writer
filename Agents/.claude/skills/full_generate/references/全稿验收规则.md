# 全稿验收规则

本文件只用于合并后检查完整剧本。

- 全稿必须按大纲连续覆盖全部集数，且每集包含场景标题、人物栏、可拍动作和至少一组中文台词。台词翻译在 `dialogue_translate` 阶段统一完成；相邻括号内目标语台词可有可无，全稿阶段不因其缺失或存在而失败。
- 每集中文可拍正文字数不得低于初始化工具按剧集时长返回的下限；空缺时按 90 秒计算。字数不包含标题和人物栏。
- 首次生成全稿时，已通过试稿范围的各集中文正文必须与 `output/剧本试稿.md` 一致；比对时忽略相邻括号内目标语台词及其换行格式。剧本改写、小说改编或爆款复刻项目进入 `full_revision` 后，不再比对试稿，前 10 集也直接以完整剧本为验收对象。
- 中文人物栏、动作和台词使用大纲名称映射中的中文名称。
- 后续剧集必须来自对应阶段文件；用户全稿不得包含阶段文件标题、梗概、创作说明、检查结果、命令或内部推理。
- 格式检查不代替后续海外审稿。整体回读修订后，必须重新合并并再次执行格式检查。
