# 剧本格式规范

- 每集使用初始化工具写入的 `## 第N集：剧集名称` 标题；每场使用 `### 集-场 日/夜 内/外 地点` 标题，随后写 `人物：`。
- 除了台词句外，动作、表情、道具和空间调度单独成行并以 `△` 开头，只写镜头可见、演员可表演的内容。
- 中文台词写为 `人物（表演提示）：台词`，表演提示通常表述为伴随台词的：情绪神态（冷笑、愤怒、疲惫）、微小肢体动作（别过头、往前逼近、摊手）、说话状态/语气（大喊、慢吞吞、自言自语）、伴随台词的简单处境（避开对方目光），表演提示可以为空。
- 人物使用中文名称。`OS`、`VO` 等制作标记只在真实画面或表演功能成立时使用，并保持大写。
- 不用旁白、人物履历、抽象情绪或解释性文字替代行动与对白。
- △ 段落要求：
  - 动作主体：禁止用"她""他""他们"指代，必须写角色全名或简称
  - 动作对象：禁止用"它""这""那"指代，必须写道具全称
  - 位置指向：禁止用"那里""这里"指代，必须写具体地点
  - 所属关系：禁止用"她的""他的"指代，必须写"xx的"- 唯一允许出现的代词是"自己"。
- 只写可拍动作和人物行动形成的中文台词。默认不新增目标语台词；已有的相邻括号目标语台词可以保留，检查不以其有无为条件。不要写摘要、重复对白、空镜或内心分析。
