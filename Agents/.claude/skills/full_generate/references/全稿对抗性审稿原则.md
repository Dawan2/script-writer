# 全稿对抗性审稿原则

本文件只用于完成一个剧情单元后的定向自我审稿。

将当前阶段文件当作竞争对手的稿件，检查：

1. 每集是否由人物选择推进，是否存在解释、巧合、重复对白或空镜替代行动。
2. 当前单元是否承接前一单元，并由自身行动产生下一单元的压力。
3. 关系、伏笔、人物阶段和已知信息是否与大纲及角色小传一致。
4. 动作是否可拍，中文台词是否真正推动行动；目标语翻译留到 `dialogue_translate` 阶段，已有目标语台词不作为本阶段审稿问题。
5. `爆款复刻`时，回读 `output/爆款分析报告.md`，确认报告中明确的剧情功能、权力关系、冲突机制和情绪回报已被新故事行动转化；不沿用具体设定，也不把报告推断当作剧情事实。

每条建议必须定位到具体集数和场景，说明最小修改动作。只修订当前阶段文件中的命中内容，不修改试稿章节或其他阶段文件。
