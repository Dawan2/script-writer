# 小说剧情单元取舍原则

1. `adaptation_plan` 只计算故事梗概的容量：前 3 个故事梗概单元每个最多 5 集，之后每个最多 7 集。它不限制小说解读中原著剧情单元的数量。
2. 只能使用“读取改编上下文”工具返回的小说解读。该结果已移除用户未确认的“保留”“删除”“合并”建议及其原因；已经不存在的节点是用户确认删除的内容，不再传递。
3. 返回单元中没有 `已确认合并` 字段的，完整保留其核心行动、关键因果、关系变化和高光回报；可以压缩描写与重复对话，但不能失去独立戏剧作用。
4. 返回单元中带有 `已确认合并: true`、`合并目标单元ID` 和合并原因的，必须将标明的高光、主线推进和必要因果融入目标单元；不得另起一个改编剧情单元，也不得只用背景说明替代人物行动和局面变化。
5. 开篇或改编剧情单元的 `原著剧情单元` 只记录工具返回的实际吸收来源。每个返回的原著单元都必须被关联；已确认合并的单元必须和目标单元共同记录。
6. 开篇第 1 集计入第一个故事梗概单元。按 `outline_unit_budgets` 逐个控制单元集数，原著单元可以在同一个故事梗概单元中重组，但总容量不能超限。
