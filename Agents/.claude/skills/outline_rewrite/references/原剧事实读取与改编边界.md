# 原剧事实读取与改编边界

本文件只用于从原始剧本提取大纲事实，并确定改写不可越过的边界。

## 读取动作

1. 先识别主线冲突、人物关系、关键选择、信息差、转折事件和原剧结局。
2. 对每个计划写入大纲的事件，确认它在原剧中的起因、行动者、结果和对后续的影响。
3. 事实或人物状态不清时，继续读取相邻片段；不要从旧草稿、公开简介或常见套路补全事实。

## 改编边界

- `output/原始剧本.md` 是唯一可补充故事事实的来源。
- 已完成的世界观决定制度、职业、地点和关键概念的改写方式；改写后仍须保留原事件的冲突功能、人物关系和选择代价。
- 需要更多集数时，只拆分原剧已有的场次、因果和转折，不在原结局之后续写剧情。
- 不把后期人物已知的信息、获得的资源或形成的关系提前写入前期剧集。
