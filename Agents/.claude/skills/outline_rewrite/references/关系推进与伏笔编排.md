# 关系推进与伏笔编排

本文件只用于安排大纲中的关系变化、信息埋设和后续回报。

## 关系推进

- 每段核心关系都要落到事件路径：一方的选择 -> 另一方的判断或误读 -> 对方的回应 -> 局面代价。
- 让人物因自身目标、恐惧或利益作出回应；不要用“感情升温”或“关系恶化”代替具体行动。
- 在相应剧集的开场冲突、主要转折和结尾承接中留下关系变化，使变化能够被下一集继承。

## 伏笔与回报

- 重大秘密、身份、立场或关系揭示，先用原剧中可追溯的异常、选择或信息差建立观众理解，再让揭示改变当前人物选择。
- 伏笔必须服务后续事件的因果，不能为了制造反转补造原剧和世界观之外的关键事实。
- 单元结尾的悬念必须由单元内人物行动造成，并在下一单元转化为可执行的目标、代价或选择。
