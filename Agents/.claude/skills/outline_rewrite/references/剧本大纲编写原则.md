# 剧本大纲编写原则

本文件只用于将原剧事实和已确定世界观组织为故事梗概、开篇、剧情单元与分集大纲。

## 角色本地化命名

- 在写故事梗概前，先完成全部关键角色的名称映射。`requires_translation` 为 true 时，英文名称是海外发行的命名事实，应符合目标地区和具体市场的常见命名习惯；中文名称是该英文名的中文音译显示名，不是把原中文名直译或保留。`requires_translation` 为 false 时，两项均保留原著中文名，不进行名称转译或本地化。
- `关键角色名称映射` 只保留英文名称和中文名称。故事梗概、开篇、剧情单元、分集梗概、写作思路和所有 `关键角色` 列表统一使用对应的中文名称。
- 世界观中已经出现的具体角色，必须沿用既定名称；海外改编补齐对应英文名称，国内改编保留原著中文名，不得在大纲阶段另起名称。
- 不同角色不能共用英文名或中文名称。后续角色小传、试稿和全稿沿用此映射，不得在下游重新命名。

## 故事梗概

- 先确认主角的目标、阻碍、主动选择和最终代价或回报，再写成一段完整因果叙述。
- 交代冲突如何建立、如何升级、关键转折如何改变人物选择，以及结局如何回应主线；不要写成宣传语或逐集目录。
- 世界观映射必须改变人物可采取的行动方式，而不是只替换地点、职业或名词。

## 剧情单元

- 第 1 集单独写入“开篇”，不归入剧情单元。开篇描述要说明第一集建立的即时冲突、主角处境和由行动造成的后续问题；它是观众进入故事的观看承诺，不重复整季故事梗概。
- 第 1 集的第一段应尽快让观众看见正在发生的冲突和主角的目标或压力。背景、世界观和人物履历只能服务这次冲突，不能先做静态说明；结尾必须由本集行动造成下一集需要承接的代价、发现或选择。
- 使用“剧情单元”表示一段共享主要目标或戏剧压力、内部连续推进的故事。它可以因目标转换、关系反转、信息揭露、权力变化或阶段回报而结束。
- 每个单元从第 2 集开始，说明开始时的压力、单元内的关键变化和结束时交给下一单元的问题。开篇、相邻单元的剧集必须连续、无重复、无空档。
- 单元数量和长度由因果推进决定；全剧总集数必须等于用户填写的目标集数，未填写时为 35 集。

## 分集大纲

- 每集从即时冲突进入，经由人物的选择和至少一个有效转折改变局面，再以该集行动造成的未解压力承接下一集。
- `剧集梗概` 写人物做了什么、因此发生了什么、局面如何变化；不要只罗列情绪、主题或事件标题。
- 相邻剧集应使目标、信息、关系、资源或风险至少一项发生变化，避免同一冲突换说法重复出现。
- `写作思路` 用于确保因果完整；用户文件只展示剧集名称、关键角色和剧集梗概。
