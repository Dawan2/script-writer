# 世界观构建原则

## 交付目标

世界观要说清故事发生在怎样的社会与规则中，权力、资源、关系和行动受到什么约束，以及什么根本矛盾使主线冲突持续成立。它是后续剧情的固定生态，不是剧情梗概或宣传文案。

## 事实与改写边界

1. 以`执行规范.md`中的当前任务事实和要求为准，不从旧会话、其他项目或未列入的偏好补充设定。
2. 剧本改写必须保留原剧的人设内核、剧情因果、人物关系、核心冲突、情感主旨和结局功能；只替换目标地区无法成立的制度、场景、社交方式与文化符号。
3. 本地化映射必须保留原概念的剧情功能、权力关系或冲突作用，不做字面换名，不为地域氛围添加与因果无关的刻板元素。
4. 爆款复刻只保留分析报告中已确认的剧情功能和冲突机制，不复制原作具体人名、地点、专有设定或连续桥段。

## 世界观描述

1. 从一个能改变人物选择或冲突结果的核心设定出发，说清它对资源、权力、阶层、关系或日常行动的影响。
2. 建立“环境或规则 → 人物可以做什么 → 必须承担什么 → 根本矛盾为何持续”的因果链。
3. 只描述世界的稳定运行方式；不叙述具体人物经历、事件过程、反转或结局。
4. 涉及具体国家的法律、医疗、教育、职业或商业制度时，只写已确认的内容；不确定的细节保留边界，不把猜测写成事实。
5. 世界观的字数不超过 500 字。

## 关键概念映射

1. 只写会影响剧情、人物关系或冲突机制的原剧概念；没有需要替换的概念时保持空列表。
2. 映射后概念必须在目标地区的制度、社交常识与生活逻辑中成立，并承担与原概念等价的地位、情绪和剧情功能。
3. 只填写“原剧本概念”与“映射后概念”，不在字段中追加说明、作用分析或备注。
4. 确需提及角色时，正文只使用已确定的中文音译显示名，不新增人物名称映射字段。
5. 映射两端的内容，可以包括但不限于：地点设定映射、组织和势利关系映射、核心道具映射等。

## 准出要求

1. `2.1-world-view.json` 顶层只包含“世界观描述”和“关键概念映射”。
2. “世界观描述”是非空字符串，且不写成剧情梗概。
3. 每条概念映射只包含两个非空字段；不需要映射时使用空列表，不填占位内容。
4. 逐条满足`执行规范.md`中当前创作原则的通过标准；例外成立时，按该原则的“例外与失效情况”处理，不强行套用。
