# 剧情单元提炼原则

## 原著剧情单元

1. 一个剧情单元是一段共享主要目标或戏剧压力的连续故事。当目标、核心关系、信息优势或权力位置发生不可逆变化时，结束当前单元。
2. 剧情单元遵循原著因果顺序和真实节奏，不按目标集数倒推数量，也不提前进行冲突前置、分集或本地化。
3. 单元梗概写清“谁为了什么采取行动—受到什么阻碍—局面如何变化”；主线推进只写该单元对全书主因果新增的贡献。
4. 关键人物只保留在本单元承担行动、阻碍、关系或信息功能的人物，并写清其作用与变化。
5. 关键信息只记录会影响人物选择或观众预期的秘密、误解、证据、身份和认知差。
6. 高光优先选择公开对抗、身份揭晓、关系决裂、主动反击、重大损失、真相反转或强情绪兑现。每个高光只保存名称和精确原文索引。

## 改编建议

1. 先完整提炼原著剧情单元，再根据目标剧本容量判断取舍；不能为了压缩而省略原著中的关键因果、高光或人物变化。
2. 承担主线因果、持续冲突升级、关键关系或信息变化、不可替代高光的单元建议“保留”。
3. 不改变后续选择、没有独立回报且功能重复的单元建议“删除”；建议原因要说明仍需快速交代的结果或必要信息。
4. 不值得独立展开，但含有高光、主线推进或后续必要因果的单元建议“合并”；建议原因要说明应融入目标单元的具体内容。
5. 至少保留一个承担核心主线的剧情单元；建议合并必须指向建议保留的单元，不能指向自身或另一个合并单元；其他建议不填写合并目标。
6. 改编建议只有在确认后才能改变后续实际传递的原著内容。
