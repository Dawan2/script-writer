# 小说全文解读原则

## 原著事实

1. 以原文中实际发生的行动、选择、阻碍和结果为依据，不用简介、类型套路或人物标签补全情节。
2. 把叙事整理为连续因果：人物因何行动、采取什么行动、受到什么阻碍、局面发生什么变化、这一变化如何引出后续事件。
3. 记录人物在身份、目标、关系、认知、资源和立场上的变化；没有造成状态变化的心理、环境和重复对话只保留其剧情功能。
4. 区分事实与认知。秘密、误解、证据和身份信息要写清何时出现、谁已知情、何时揭示或被推翻。
5. 重要事实、人物转变和高光都必须能回到准确的原文范围。索引覆盖完整的动作、反应和结果，不扩大到无关内容。
6. 以一次会改变后续行动的事件为最小整理单位，完整保留起因、人物选择、阻碍或转折、结果及后效；同步记录身份、目标、关系、认知、资源或立场变化。不同字段不重复转述同一事实。

## 全局理解

1. 后文揭晓新事实时，修正前文暂时认知；最终结论不能同时保留互相冲突的版本。
2. “关键人物”只列全书主要角色，不按出场次数筛选，也不为凑数量补人。最多 10 人；每人应持续改变主线，并满足以下至少两项：跨 3 个及以上剧情单元发挥作用；会作出改变关键因果或核心关系的独立选择；其关系走向或最终结局是作品需要兑现的观众问题。承载全书核心伏笔或世界观秘密是强加分项，但不是必备条件；终局对手或秘密核心人物即使覆盖单元较少，只要决定主线终局，也可保留。
3. 剧情单元的关键人物用于记录该单元内承担行动、阻碍、关系或信息功能的人物，可以包含未列入全书“关键人物”的局部角色。人物画像只为全书主要角色撰写，并包含身份、核心欲望、关系变化与转变关键事件。
4. 故事主线由主角的核心行动、阻碍升级、代价和最终结果构成；支线只在改变这条因果链时进入主线。
5. 核心卖点说明观众持续追看的承诺，以及故事用什么冲突、关系或信息回报反复兑现它。
6. 世界观只记录会限制人物行动、制造冲突或改变结果的环境、秩序和规则。
7. 完成全局理解后，从结局向前检查因果支撑、伏笔兑现、人物转变和剧情连续性。
