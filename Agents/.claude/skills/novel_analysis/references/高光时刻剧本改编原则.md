# 高光时刻剧本改编原则

1. 高光原文是忠实锚点。先通过原文索引读取正文，再写该场景；不得凭摘要补造关键台词、动作、画面或情绪结果。
2. 保留原著高光中的核心行动顺序、关系位置、信息揭示、标志性台词含义和情绪回报；调整只能服务于可拍性、短剧节奏与本地化表达。
3. 将心理和叙述转成可观察的表演、动作、场面调度或有行动目的的台词。可以压缩过渡和重复表达，但不能改变该高光为何发生及它造成的结果。
4. 标志性台词可在不改变意图和关系力量的前提下缩短；不得为了口号感加入原著人物不会说、且与当前人物阶段冲突的表达。
5. 高光前后的衔接由改编大纲决定；若原文细节与已确认的改编世界观或角色名称不同，只替换外壳，保留戏剧功能和情绪兑现。
