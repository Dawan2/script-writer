# 试稿自我审稿原则

本文件只用于完成试稿后的对抗性审稿与定向修订。

把当前稿件当作竞争对手的剧本，逐集寻找会让观众停止观看或让制作无法执行的问题：

1. 第 1 集是否迅速建立冲突、主角压力和下一集问题。
2. 每集是否由人物选择推动，而不是靠解释、巧合或重复问答推进。
3. 相邻集的关系、信息、时空和结尾承接是否一致。
4. 动作是否可拍，中文台词是否有对象、目的和回应；目标语台词不作为本阶段的审稿问题。
5. 对于不同的场景，再叠加不同侧重的审稿方向：
   - `小说改编`：逐项核对工具返回的原文高光；
   - `爆款复刻`：回读 `output/爆款分析报告.md`，核对报告中明确的剧情功能、权力关系、冲突机制和节奏承诺是否已被新故事行动转化；不沿用具体设定，也不把报告推断写成既定事实；

每项建议必须定位到具体集数和场景，并说明最小修改动作。只修改命中内容，不重写通过的其他集，也不扩展试稿范围。
