# 剧本设定解析原则

本原则只用于把仍为“自动适配”的受众、主题、背景、设定转换为受控标签。用户已明确选择的字段不得改写。

## 判断顺序

1. 先确认完整主线、主要冲突、主角的持续行动和终局回报；不要只看标题、简介、开篇噱头或原材料自带标签。
2. 从 `.claude/config/script-tag-taxonomy.json` 的对应分类中选择；不得发明近义标签。
3. 证据不足时少选，不为覆盖词表而凑标签。主题、背景、设定各最多四项；受众必须且只能一项。
4. 调用“解析剧本设定”工具写回结果。自动补全结果被工具拒绝时必须重新判断，不得绕过校验直接修改项目输入。

## 四类标签

- 受众：按主要代入路径和终局回报判断，不按主角性别判断。权力扩张、征服升级、资源占有通常偏男频；关系选择、自我成长、情感公平与身份认同通常偏女频。存在多种回报时，选择贯穿主线且在终局兑现的一种。
- 主题：选择持续组织主线冲突的题材类型。局部案件、短暂恋爱线、单次喜剧桥段或开篇引子不能单独决定主题。
- 背景：选择主要剧情任务实际发生的时空与社会场域。穿越前、回忆或短暂支线不算主背景。自动补全时，“现代、古代、年代、民国”最多选择一个，可以同时补充都市、乡村、职场、校园、宫廷、荒岛等主要场域。
- 设定：选择反复改变人物行动、信息差、资源分配或回报方式的故事机制。普通职业、偶发能力、一次性误会不算设定；只有持续驱动主线时才选择医生、娱乐圈、异能等标签。

## 完成标准

- 四类标签都已从受控词表中确定，不再含“自动适配”。
- 自动补全的标签能够由完整主线和终局回报解释，不与用户选择冲突。
- 用户明确选择的标签保持原样；工具返回的 `preserved_fields` 不得被后续步骤覆盖。

## 标签一致性

以下规则只约束自动补全的标签。用户已选择的字段不得修改；两个相关字段均由用户选择时，即使语义上不一致也必须保留。只有一个字段由用户选择时，调整另一个自动补全字段。

- 自动补全背景时，“现代、古代、年代、民国”最多选择一个主背景。
- 现代言情不能与古代、宫廷、年代或民国主背景同时使用。
- 古风言情不能与现代、都市、职场或校园主背景同时使用。
- 年代爱情不能与现代、古代或民国主背景同时使用。
- 民国爱情不能与现代、古代或年代主背景同时使用。
- 待补全标签与用户已明确标签冲突时，调整待补全标签，不得改写用户选择。
