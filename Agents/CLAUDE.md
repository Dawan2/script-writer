这是一个基于 Claude Code 的“剧本出海”Agent 项目，用来把用户提供的国内短剧剧本或小说改造成短剧剧本。

# 项目说明
1. 剧本改写这不是翻译项目，而是跨文化改编项目：保留原剧的爽感引擎、核心宿命冲突、关键伏笔和终局反转，重构文化外壳、人物动机、场景、对白和叙事顺序。
2. 角色命名先定海外英文名，再用英文名音译作为中文音译显示名；中文正文用音译名，括号内目标语台词提到人物时用英文名。
3. 质量优先于成本：不得为了减少 token 删除必要剧情事实、角色状态、源引用或审批门。

# SKILL说明

1. `project_init`：创建项目工作区，归档源文件与附件，将剧本转换为 `output/原始剧本.md`、小说转换为内部文件 `runtime/原始小说.md`，并初始化项目输入与进度。
2. `novel_analysis`：仅用于小说改编，生成 `2.1-novel-analysis.json` 与原文索引，提炼基础信息、卖点、主线、世界观、关键人物和剧情单元。
3. `world_view`：仅用于剧本改写；基于原始剧本、用户要求和目标地区规则，生成 `2.1-world-view.json`。
4. `outline_rewrite`：剧本改写读取原剧本与世界观，小说改编读取小说解读；重构短剧故事并生成 `3.1-outline.json` 与 `output/剧本大纲.md`。
5. `character_rewrite`：基于剧本大纲完善关键角色的资产画像、诉求、关系弧光与阶段完整状态，生成 `4.1-character.json` 与 `output/角色小传.md`。
6. `trial_generate`：基于改编上下文、大纲和角色小传生成前 10 集或全部可用剧集的中文试稿，输出 `output/剧本试稿.md`；小说改编按大纲关联的高光索引读取必要原文。
7. `full_generate`：以已通过的试稿为前置，按剧情单元生成并合并完整中文剧本，输出 `output/剧本全稿.md`；小说改编按当前单元索引读取必要原文。
8. `dialogue_translate`：基于完整中文剧本统一翻译台词，输出以剧本名称命名的 `output/*-台词译稿.md`；也可作为独立台词翻译场景运行。
9. `foreign_review`：审读完整剧本及台词译稿，形成六维评分、正文证据、风险和返修路径，输出 `review-scorecard.json` 与 `output/审稿报告.md`。
