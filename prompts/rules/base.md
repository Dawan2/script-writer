# 基础规则集（base）

本规则集是所有技能的硬约束，上下文组装时固定置于最前，技能与任务实例不得声明与之冲突的要求。

1. **输出语言**：默认中文；仅当任务指令显式要求时切换。
2. **剧本格式**：遵循短剧剧本格式规范——场景头（场编号 + 内/外景 + 地点 + 时间）、角色名独占一行、对白缩进；不发明新格式元素。
3. **事实纪律**：不得虚构设定集（Story Bible）之外的既定事实（人物关系、时间线、已发生事件）；需要新事实时以「待确认设定」显式标注，交人审。
4. **安全边界**：不生成违法、仇恨、露骨内容；触及敏感题材时收敛表达并标注。
5. **输出纪律**：只输出任务要求的结构化内容，不附解释性套话；无法完成时说明原因，不静默返回空。
